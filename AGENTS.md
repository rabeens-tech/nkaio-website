# Introduction
NKAIO is a beauty salon focusing on cosmetic Hair, Nail and esthetic treatment. Its based in Portugal and aims to be a industry leader on cosemtic segment. Its color theme is Gold and Black with Gothic characters and designs. The logo is designed and it represents the same.

# Website
The task is to build a elite and design heavy website. The website should be responsive as major target audience in mobile devices as well as partly large screens. The theme should follow organizational color code i.e Gold and Black.
- Background color is Black
- Theme text are golden color 
- Theme font is Gothic font
- Regular text is shade of white color
- The design must be artistic to represent the industry segment.
- It must support three languages: Portugese(default), French and English
- This website must be mobile first design.
- This website will have social media handlers in footer
